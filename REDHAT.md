# AI Attribution Policy

This project follows Red Hat's [guidelines for responsible use of AI code
assistants](https://source.redhat.com/projects_and_programs/ai/wiki/code_assistants_guidelines_for_responsible_use_of_ai_code_assistants).

## Attribution

- `Assisted-by: Claude Code (claude.ai/code)` — human-directed work with AI assistance
- `Generated-by: Claude Code (claude.ai/code)` — large generated blocks with minimal human edit

## Rules

- No confidential, personal, or proprietary/customer data in prompts
- Synthetic data in all code, tests, and examples
- If AI output resembles third-party code, investigate license implications
- Never use `Co-Authored-By:` for AI tools
